# KALK AYAĞA — Türkiye Milli Takımı Stadyum Marşı

**Durum:** FİNAL (kilitli) · **Araç:** Suno v5 (Pro) · **Tarih:** 2026-06-05

Kimlik kararı: **KALK AYAĞA** çizgisi seçildi (alternatif "BİRLİKTE" arşivde).
Gerekçe: tribün motoru güçlü, bağırılabilir hece yapısı, ballad riski düşük.
"Kalk ayağa" çift anlamı (ayağa kalk + zorluktan sonra yeniden doğ) projenin
şifa/birlik ruhunu korur, jenerikleşmeyi önler.

---

## Bu finalde uygulanan 3 düzeltme

1. **"Tek yürek daha" → "Tek yürek burada"** — zorlama kafiye gitti, "buradayız"
   teması güçlendi.
2. **Final kanca enflasyonu çözüldü** — zirvede 4 yarışan slogan yerine tek patron
   kanca: **"KALK AYAĞA / BURADAYIZ"**. "Umut biziz / Birlikteyiz" yalnızca bir
   nefes-arası olarak kaldı, sonra ana kancaya dönüyor.
3. **"Kalk ayağa" çift anlamı bilinçli vurgulandı** — şifa/birlik ruhu korundu.

---

## SUNO — STYLE kutusu

```
Turkish cinematic stadium anthem, 108 BPM, A major, marching toms + taiko heartbeat, heroic brass fanfare, huge gang-vocal crowd choir, claps, bright airy top end, stadium reverb, male lead growing into massive singalong, heroic uplifting — NOT ballad
```

## SUNO — EXCLUDE STYLES kutusu

```
slow ballad, acoustic, arabesque, military march, EDM drop, trap, aggressive rock, generic pop, lo-fi, sad
```

## Üretim sırası (Suno v5)

1. Style + Exclude + Sözleri gir → **3–5 üretim** al.
2. En iyi vokal/tını → **Persona** kaydet (tutarlılık için).
3. Final patlamasını uzatmak istersen → o parçada **Extend**:
   *"final chorus, full stadium gang vocals, repeat KALK AYAĞA / BURADAYIZ
   call-and-response, hard stop."*
4. Bitişte **Remaster** (parlaklık + yükseklik).
5. İstersen **Stems** indir → finalde alkış/kalabalık katmanını elle kalınlaştır.

## Kabul kriteri (üretimi alınca kontrol)

- [ ] İlk ~8 sn'den sonra pulse/davul giriyor mu?
- [ ] Verse 2 enerjiyi düşürmüyor mu?
- [ ] "Türkiye! Türkiye! → Buradayız burada!" gerçek çağrı-cevap mı?
- [ ] "YENİDEN!" üçlüsü kademeli büyüyor mu?
- [ ] Final ≥45 sn ve tek kancaya kilitli mi?
- [ ] Mix parlak mı (Lyria'nın "karanlık balad" sorunu çözülmüş mü)?

## Notlar — Suno gerçeği (eski Gemini/Lyria kısıtları geçersiz)

- **3 dk sınırı** Lyria'ya aitti; Suno v5 daha uzun üretir + Extend ile uzatılır.
- **"Karanlık mix / parlaklık yok"** Lyria'ya aitti; Suno v5 daha parlak, Remaster ile düzelir.
- **10.000 karakterlik düzyazı prompt** Suno'da ters teper; Style kutusu kısa (~150–250
  karakter) + meta-tag'li sözler doğru yöntem.

## Arşiv — alternatif kimlik (BİRLİKTE)

Ana kanca "Ooooo... Birlikte..."; daha sinematik/duygusal ama ballad'a kayma riski
yüksek. Tam söz taslağı proje konuşma dökümünde saklıdır; bu finalde kullanılmadı.
